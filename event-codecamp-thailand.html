ผลลัพธ์การเรียนรู้

วัตถุประสงค์หลัก

"เพื่อสร้างบุคลากรที่มีความเชี่ยวชาญในการบูรณาการระบบความปลอดภัยเข้ากับกระบวนการพัฒนาซอฟต์แวร์ (DevSecOps) โดยสามารถประยุกต์ใช้เทคโนโลยีปัญญาประดิษฐ์ (AI) และระบบอัตโนมัติ เพื่อยกระดับความปลอดภัยและความรวดเร็วในการส่งมอบซอฟต์แวร์ขององค์กรให้สอดคล้องกับมาตรฐานสากล"

การจัดหมวดหมู่ตาม 3 ด้านหลัก

1. ทักษะเทคนิค (Technical Skills)

  • สร้างและบริหารจัดการ CI/CD Pipeline ที่มีการตรวจสอบความปลอดภัยอัตโนมัติ (SAST, SCA, DAST) ได้อย่างสมบูรณ์
  • เลือกใช้และสั่งการ เครื่องมือ AI เพื่อช่วยเขียน Secure Code และตรวจสอบ Unit Test ได้อย่างแม่นยำ
  • ออกแบบและติดตั้ง Cloud ด้วย Infrastructure as Code (IaC) พร้อมการจัดการ Secrets อย่างปลอดภัย
  • จัดการความปลอดภัย ของ Container และ Docker Images ตามมาตรฐานสากล

2. ทักษะคิดขั้นสูง (Cognitive Skills)

  • วิเคราะห์และแยกแยะ ความแตกต่างระหว่าง DevOps และ DevSecOps เพื่อวางแผนปรับปรุงกระบวนการทำงาน
  • ประเมินความเสี่ยงและตัดสินใจ แก้ไขช่องโหว่ (Vulnerability) โดยใช้คำแนะนำจาก AI ประกอบการตัดสินใจ
  • ออกแบบกลยุทธ์ การเฝ้าระวัง (Monitoring) และระบบจัดการสิทธิ์ (IAM) ที่รัดกุมและยืดหยุ่น

3. ทักษะวิชาชีพ (Professional Skills)

  • ประยุกต์ใช้ หลักการ Policy as Code เพื่อควบคุมมาตรฐานความปลอดภัย (Compliance) ขององค์กร
  • สร้างและนำเสนอ โปรเจกต์ต้นแบบ (Prototype) ที่รวมกระบวนการ DevSecOps ทั้งระบบ

สื่อและอุปกรณ์

  • คอมพิวเตอร์ประสิทธิภาพสูง (รองรับ Docker/Virtualization)
  • การเชื่อมต่ออินเทอร์เน็ตความเร็วสูง
  • บัญชี Cloud Platform (AWS/Azure) และบัญชี AI Services (OpenAI/Copilot)
  • ระบบ Lab จำลอง (Sandbox Environment)

สิ่งที่ส่งมอบ

1. เอกสารหลักฐานการเข้าร่วมและประเมินผล

  • รายชื่อผู้เข้าอบรมฉบับสมบูรณ์ (1,400 คน)
  • หลักฐานการเข้าเรียน (Sign-in Sheets / System Login Logs)
  • แบบประเมินความพึงพอใจ
  • ผลการประเมินการเรียนรู้ (Pre-Test / Post-Test, Lab, Capstone)
  • สำเนาประกาศนียบัตร

2. เอกสารและเนื้อหาการสอน

  • สไลด์บรรยาย, เอกสารประกอบ, คู่มือปฏิบัติการ
  • ลิงก์ Source Code Repository, วิดีโอบันทึกย้อนหลัง

3. ภาพรวมและการบริหารจัดการ

  • รายงานสรุปผลการฝึกอบรม (Executive Summary)
  • ภาพถ่ายกิจกรรม, สื่อประชาสัมพันธ์
  • เอกสารการเงิน
