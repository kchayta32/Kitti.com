แผนการพัฒนาเกม HTML5

เป้าหมาย

สร้างเกม RTS (Real-Time Strategy) ที่เล่นได้จริงบน Web Browser โดยใช้ HTML5 Canvas และ Vanilla JavaScript โดยอ้างอิงฟีเจอร์จากเกม Unity ที่มีอยู่

ฟีเจอร์หลักที่จะสร้าง
1. Core Game Engine
  • Canvas Rendering - วาดแผนที่, หน่วยรบ, UI บน HTML5 Canvas
  • Game Loop - 60 FPS update/render cycle
  • Input System - การคลิกเลือกหน่วย, การสั่งเคลื่อนที่, การโจมตี
2. ระบบหน่วยรบ (Units)
ประเภท ตัวอย่าง บทบาท
⚔️ ทหารราบ พลดาบ, พลหอก พื้นฐาน
🐎 ม้า ม้าศึก โจมตีเร็ว
🐘 ช้างศึก ช้างศึก Tank/Siege
🏹 ธนู นักธนู ระยะไกล
3. ระบบทรัพยากร
🌾
อาหาร
จากนาข้าว/ฟาร์ม
💰
ทอง
จากเหมือง/การค้า
4. ระบบ AI ศัตรู
  • Patrol หน่วยในพื้นที่
  • โจมตีเมื่อพบศัตรู
  • การเคลื่อนที่แบบ A* Pathfinding (simplified)
5. UI/HUD
  • แถบทรัพยากร (บน)
  • Minimap (ล่างซ้าย)
  • ข้อมูลหน่วย + คำสั่ง (ล่าง)
