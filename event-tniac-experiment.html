ภายในรอบทดลองแรก ให้ได้ 3 อย่างนี้ก่อน:

  • เปิดกล้อง/วิดีโอ → ตรวจพบหมวก/เสื้อสะท้อนแสง/คน พร้อมกรอบ (bounding box)

  • วัด Latency ต่อเฟรม (ms/frame) + บันทึกผลเป็นไฟล์ (CSV)

ถ้าทำ 3 ข้อนี้ได้ = "ของจริง" พร้อมต่อยอดเป็นพฤติกรรมเสี่ยง + งานวิจัย

PPE ที่แนะนำให้เริ่ม
Helmet (หมวกนิรภัย) Safety Vest (เสื้อสะท้อนแสง)

  • Safety vest: vest / no-vest (ถ้ามีข้อมูลพอ)
พฤติกรรมเสี่ยง (เฟส 2 หลังจาก PPE รันจริง)

เริ่มจาก "เชิงตรรกะ" ก่อน ไม่ต้อง deep action recognition ทันที:

  • เข้าเขตอันตราย: วาดโซน (polygon) แล้วถ้าคนเข้า → แจ้งเตือน
  • อยู่ใกล้วัตถุอันตราย: ระยะคน-เครื่องจักร/พื้นที่งาน > threshold
  • ล้ม/นั่งนานผิดปกติ: (ถ้าจะต่อยอด) ค่อยไป pose estimation

  • เริ่มจาก person detection ก่อน (มักมี pretrained ให้ใช้)
  • จากนั้นทำ PPE เป็นโมเดลเล็กอีกตัว (helmet/vest) ที่รันเฉพาะบริเวณ "หัว/ลำตัว" ของคน

✗ ข้อเสีย: ต้องมีข้อมูล PPE สำหรับเทรน/ปรับแต่ง

แนวทาง 2: YOLO แบบ end-to-end

ง่ายด้านความแม่น แต่หนักขึ้น

  • คลาส: person, helmet, vest
  • วัด FPS/latency ตามภาพจริง

✓ ข้อดี: ง่ายเรื่องตรรกะ, ผลลัพธ์สวย

✗ ข้อเสีย: โมเดลใหญ่กว่าและกินเครื่อง ถ้า Edge อ่อนต้องจูนหนัก

คำแนะนำ: ถ้าอยาก "ได้ผลจริงเร็ว" เชียร์ แนวทาง 1 (person ก่อน + PPE ROI)

การวัด FPS/Latency ให้เป็นมาตรฐาน (ใช้ในบทความได้ทีหลัง)

เก็บ 3 ค่าเสมอ:

ค่าที่วัด คำอธิบาย
Preprocess time resize/normalize
Inference time เวลารันโมเดล
Postprocess time NMS/overlay

แล้วคำนวณ:

  • Latency/frame = preprocess + inference + postprocess
  • FPS จริง = 1 / latency เฉลี่ย (หรือ rolling average)

เก็บลง CSV:

// CSV Format
timestamp, frame_id, preprocess_ms, inference_ms, post_ms, total_ms, fps

function [angleDeg, conf, lineOut] = estimate_tilt_hough(I, bbox_xywh)
% I: image (RGB or gray)
% bbox_xywh: [x y w h] in pixels

  % --- crop ROI + padding ---
  pad = 0.10; % 10% padding
  x = bbox_xywh(1); y = bbox_xywh(2);
  w = bbox_xywh(3); h = bbox_xywh(4);

  % --- preprocess ---
  G = rgb2gray(ROI);
  G = imgaussfilt(G, 1.0);
  E = edge(G, "Canny");

  % --- Hough line detection ---
  [Hh, Th, Rh] = hough(E);
  P = houghpeaks(Hh, 8);
  L = houghlines(E, Th, Rh, P);

  % --- เลือกเส้นเด่น: ยาวที่สุด ---
  lens = arrayfun(@(s) norm(s.point1 - s.point2), L);
  [bestLen, idx] = max(lens);
  best = L(idx);

  % --- คำนวณมุมเส้น ---
  angleDeg = atan2d(dy, dx);
end

% estimate_tilt_hough (UPDATED)
% - เลือกเส้นใกล้แนวนอนเท่านั้น (กันหลงไปเส้นแนวดิ่งจนได้ 90°)
% - ถ้าไม่เจอเส้นแนวนอน => conf = 0 และ angle=0 (ไม่ trigger)

  % --- crop ROI + padding ---
  pad = 0.12;
  x = bbox_xywh(1); y = bbox_xywh(2);
  w = bbox_xywh(3); h = bbox_xywh(4);

  % ... crop and preprocess ...

  % --- Hough line detection ---
  [Hh,Th,Rh] = hough(E);
  P = houghpeaks(Hh, 12, "Threshold", ceil(0.35*max(Hh(:))));
  L = houghlines(E, Th, Rh, P, "FillGap", 12, "MinLength", 50);

  % --- คัดเฉพาะเส้นใกล้แนวนอน (|angle| <= 25 deg) ---
  maxAbsAngle = 25; % ปรับได้ 20-35
  keep = (abs(angles) <= maxAbsAngle);

  L2 = L(keep);
  angles2 = angles(keep);
  lens2 = lens(keep);

  % ถ้าไม่เจอเส้นแนวนอนเลย: ไม่มั่นใจ (ไม่ trigger)
  if isempty(L2)
    angleDeg = 0; conf = 0;
    lineOut = struct("point1",[NaN NaN],...);
    return;
  end

  % --- เลือกเส้นเด่น: ให้คะแนนจากความยาว + ใกล้ 0 deg ---
  % score = length * (1 - |angle|/maxAbsAngle)
  score = lens2 .* (1 - min(abs(angles2), maxAbsAngle)/maxAbsAngle);
  [bestScore, idx] = max(score);
  best = L2(idx);

  % --- confidence (0..1) ---
  diagLen = hypot(size(ROI,1), size(ROI,2));
  conf = min(1, bestLen / diagLen);
end

  • ภาพถ่ายสมจริง, 16:9, กลางวันแสงธรรมชาติ, รายละเอียดสูง, สีธรรมชาติ, กล้องนิ่ง, ไม่เบลอ

วิดีโอแสดงการเปลี่ยน severity จาก NORMAL → WATCH → WARNING → CRITICAL ตามมุมเอียง

สรุป: ระบบ Beam Tilt Early Warning ทำงานได้สมบูรณ์! วัดมุมเอียงแม่นยำ (ต่างจาก true < 0.1°), trigger 3 ระดับถูกต้อง, พร้อมวิดีโอเดโม่แสดงผลแบบ real-time overlay

การแก้ปัญหา: Hough Line Switching

ปัญหาที่พบจาก sequence_results.csv:

  • ช่วง 8–14° เป็น WATCH (ถูกต้อง)
  • พอ 16–20° กลับเป็น NORMAL (ทั้งที่ควรหนักขึ้น)
สาเหตุหลัก: Hough ไป "สลับเส้น"

เพราะเรา "หมุนเฉพาะ ROI" ทำให้เกิด ขอบตะเข็บ/รอย blend รอบ ๆ ROI และ Hough ชอบไปเก็บเส้นเหล่านั้นในบางมุม → มุมที่วัดเลย "กระโดด" และ severity รีเซ็ต

ทางแก้ที่เร็วและนิ่งสุด (ทำพร้อมกัน 2 อย่าง):

  1. measureRoi — วัด tilt จาก ROI ที่ "ยุบเข้าไปด้านใน" เพื่อไม่ให้เห็นขอบตะเข็บ
  2. prevAngle tracking — ทำ tracking ด้วย prevAngle เลือกเส้นที่ใกล้มุมเฟรมก่อนหน้า (ไม่สลับเส้น)
1) อัปเดต render_alert_video.m (เพิ่ม measureRoi + prevAngle tracking)
(A) เพิ่มค่ากำหนดด้านบน — วางไว้ใกล้ ๆ featherPx
measureMargin = 12; % ยุบ ROI เข้าไปเพื่อเลี่ยงขอบตะเข็บ (ลอง 8–20)
(B) หลังจากได้ roi แล้ว สร้าง measureRoi — วางต่อท้ายหลัง clamp ROI
% ROI ที่ใช้วัดจริง (ยุบเข้าไป)
m = measureMargin;
measureRoi = roi;
measureRoi(1) = roi(1) + m;
measureRoi(2) = roi(2) + m;
measureRoi(3) = roi(3) - 2*m;
measureRoi(4) = roi(4) - 2*m;

% กันกรณีเล็กเกิน
measureRoi(3) = max(20, measureRoi(3));
measureRoi(4) = max(20, measureRoi(4));
(C) ใน loop ให้ส่ง prevAngle เข้า estimate_tilt_hough + อัปเดต prevAngle

ก่อนเริ่ม loop เพิ่ม:

prevAngle = 0;

แล้วแก้บรรทัดวัด tilt จากเดิม:

[ang, conf] = estimate_tilt_hough(frame, roi); % เดิม

เป็น:

[ang, conf] = estimate_tilt_hough(frame, measureRoi, prevAngle); % ใหม่

% อัปเดต prevAngle เฉพาะตอนมั่นใจ (กันหลุด)
if conf >= confMin
  prevAngle = ang;
end
2) อัปเดต estimate_tilt_hough.m (รองรับ prevAngle + ปิดขอบ E กัน seam)

แทนที่ทั้งไฟล์ด้วยเวอร์ชันนี้ (รองรับ 2 หรือ 3 arguments):

function [angleDeg, conf, lineOut] = estimate_tilt_hough(I, bbox_xywh, prevAngleDeg)
% estimate_tilt_hough (UPDATED)
% - Ignore border edges inside ROI to avoid seam artifacts
% - If prevAngleDeg provided: prefer line angles close to previous frame

  if nargin < 3 || isempty(prevAngleDeg)
    prevAngleDeg = 0;
  end

  % --- crop ROI + padding ---
  pad = 0.12;
  ...

  % ===== กันขอบตะเข็บ: ปิด edge บริเวณขอบ ROI =====
  border = 10; % ลอง 8–16
  E(1:border, :) = 0;
  E(end-border+1:end, :) = 0;
  E(:, 1:border) = 0;
  E(:, end-border+1:end) = 0;

  % --- score with temporal preference (close to prevAngleDeg) ---
  d = abs(angles2 - prevAngleDeg);
  d = min(d, 180 - d); % wrap
  d = min(d, 90); % clamp

  % closeness weight: 1 at 0 deg diff, 0 at >=45 deg diff
  wClose = max(0, 1 - d/45);

  % base weight: prefer long lines + close to horizontal + close to prev
  wHoriz = 1 - (abs(angles2)/maxAbsAngle);
  score = lens2 .* (0.55*wHoriz + 0.45*wClose);

  [~, idx] = max(score);
  ...
end
